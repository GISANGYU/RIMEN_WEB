# 메인 릴 영상 기획 — 3안

2026-09-24 · RIMEN_WEB `#home-reel` (썸네일 → 풀스크린 워핑) 자리에 들어갈 16초 루프 영상

## 0. 왜 바꾸나 / 이 자리의 조건

지금 영상(스튜디오 전면 투사 시연)은 **카메라가 고정되고 화면 변화가 느려** 멈춘 사진처럼 보인다.
게다가 투사된 수중 유적 그림은 **스튜디오 시연용 콘텐츠라 우리 작업이 아니다.** 우리 자료로 채운다.

이 자리가 영상에 요구하는 것 (원본 셰이더가 만드는 조건):

| 조건 | 이유 | 영상 규칙 |
|---|---|---|
| **썸네일에선 흑백 + 파란 틴트** | 조각 셰이더가 `max(#1a2ffb, 밝기)` 로 칠한다 | 어두운 바탕 + 밝은 피사체. **밝기 대비로 읽혀야 한다** (색 대비는 썸네일에서 사라짐) |
| **펼쳐지면 약 2.56 : 1** | 도착 상자 1713×668 에 16:9 를 cover | 위아래 18% 는 잘린다. **글자·핵심 동작은 세로 가운데 64% 안** |
| **워핑 중에도 계속 재생** | 면이 휘는 동안 영상이 돌아야 쫄깃함이 산다 | 정지 구간 없이 **항상 무언가 움직인다** |
| **16초 끊김 없는 루프** | `loop` 재생 | 마지막 0.4초가 첫 프레임으로 녹아든다 |
| **마우스 번짐 효과** | 화면을 속도 방향으로 끈다 | 가는 선·입자처럼 **고주파 디테일**이 있어야 번짐이 예쁘다 |
| 소리 없음 · 1600×900 · 30fps · 4MB 이하 | 자동재생(음소거) | — |

## 1. 공통 콘텐츠 — "Wake Inside, the Dream"

16초 안에 **잠 → 신호 → 개화(자각) → 공간 → 다시 잠** 의 한 바퀴.
LIMEN 의 문장("타인의 기준이 내 선택에 들어와 있음을 알아차리는 순간")을 **빛이 깨어나는 순간**으로 번역한다.

우리 소재만 쓴다:
- **Night Bloom 와이드 신규 렌더** — 16:9 로 다시 렌더. 봉오리 → 만개 + 카메라 56° 궤도 (`Blender/render_wide.py`, 150프레임)
- Blender 꽃 스틸 (flower, crystal, night 봉오리/반개/만개), v1 개화 루프
- 호라이즌 스튜디오 **맵핑 그리드 테스트 사진** (원본 5712px), 워핑 보정(태블릿), 센서 뷰
- **바닥 인터랙션 테스트** (사람 발밑에 꽃)
- **AI 디퓨전** — 실루엣 마스크, 생성된 금빛 실 가닥
- LIMEN 키비주얼 (밤의 이끼·나비)
- 파이썬으로 **직접 생성하는 그래픽**: 발광 입자, 빛 번짐, 그리드·HUD, 글리치, 디더

제외: 스튜디오 시연 영상(남의 콘텐츠), 르스페이스 사진(다른 전시).

## A안 — WAKE · 리듬 몽타주 (전시 트레일러)

| | |
|---|---|
| **무드** | 깨어남, 에너지, 긴장 → 해방. "지금 눈을 떠" |
| **그래픽** | 고대비 흑백 ↔ 컬러 플래시, 화면을 꽉 채우는 굵은 타이포 (WAKE / INSIDE / THE / DREAM), 글자 모양으로 뚫린 영상(마스크), 필름 그레인 |
| **편집** | 120BPM 비트 컷(0.5초), 비트마다 줌 펀치(1.08→1), 4비트마다 휩팬 블러 전환, 화이트 스트로브, 끝부분 0.25초 가속 컷 |
| **썸네일에서** | 흑백 플래시가 파란 틴트 위에서 **깜빡이며 튄다** — 가장 눈에 띄는 안 |

```
0.0–2.0  검정 위 단어 네 개가 비트마다 번쩍 (WAKE · INSIDE · THE · DREAM)
2.0–10.0 몽타주 16컷: 맵핑 그리드 → 센서 → 봉오리 → 바닥 꽃 → 실루엣 → 금빛 실 …  (줌 펀치, 4컷마다 휩팬)
10.0–13.0 슬로모션 히어로: 와이드 개화 렌더 + 거대한 "LIMEN" 글자 속으로 영상이 비친다
13.0–16.0 0.25초 스트로브로 가속 → 검정 → WAKE 로 루프
```

## B안 — BLOOM · 자각몽 롱테이크 (몽환)

| | |
|---|---|
| **무드** | 자각몽, 느린 호흡, 경이. "꿈인 줄 알면서 머무는 순간" |
| **그래픽** | 틸–바이올렛 그레이드, 발광 입자(반딧불)가 위로 떠오름, 하이라이트 블룸, 색수차, 흐르는 빛 번짐(light leak), 얇은 세리프 한 줄 |
| **편집** | 컷 없음. 느린 푸시인 + 물결 왜곡(액체) 디졸브 3번. 개화는 0.6배속 프레임 블렌딩 |
| **썸네일에서** | 어둠 속 **흰 꽃이 피어오르는** 실루엣 — 가장 서정적 |

```
0.0–3.5  키비주얼(밤 이끼·나비) 느린 푸시인, 입자가 떠오른다
3.5–5.0  물결 디졸브 → 봉오리
5.0–12.0 와이드 개화 렌더 (카메라 궤도) + 입자가 꽃 주위를 돈다, 빛이 숨 쉬듯 맥동
12.0–14.5 물결 디졸브 → 바닥 인터랙션 (사람 발밑의 꽃) — 꿈이 실제 공간으로
14.5–16.0 흰 빛으로 번지며 키비주얼로 루프
```

## C안 — SIGNAL · 관측 로그 (R&D / 테크)

| | |
|---|---|
| **무드** | 관측, 추적, 실험실. "당신의 위치가 기록되고 있다" — 타인의 흔적이 다음 사람의 환경이 된다 |
| **그래픽** | 흑백 + 사이트 블루(#1a2ffb) 단일 액센트, 12컬럼 그리드·십자 마크(사이트의 ✕ 장식과 같은 언어), 추적 박스, 좌표 숫자, 스캔 라인, 디더링 |
| **편집** | 그리드가 그려지며 시작, 2×2 분할 멀티캠, 글리치(RGB 분리·블록 밀림) 컷, 타이핑 라벨 |
| **썸네일에서** | 사이트의 파란 틴트와 **같은 색 언어** — 사이트와 가장 일체감 있는 안 |

```
0.0–2.5  빈 화면에 그리드 선이 그려지고 좌표·라벨이 타이핑된다 (LIMEN / R&D LOG)
2.5–7.0  2×2 멀티캠: 맵핑 그리드 · 실루엣 · 센서 뷰 · 개화 — 스캔 바가 훑는다
7.0–11.5 바닥 인터랙션 풀프레임(디더) → 추적 박스가 사람을 따라가고 지나간 자리에 점이 쌓인다 (= 타인의 흔적)
11.5–14.0 글리치 컷 → 금빛 실 가닥을 블루 듀오톤으로
14.0–16.0 그리드가 가운데로 접히며 루프
```
