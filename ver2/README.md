# ver2 — LIMEN 인터랙티브 포트폴리오

seunghyuk.com 의 인터랙션 구조를 분석해(`ANALYSIS.md`) LIMEN 졸업작품의 의미로 다시 설계한 시안.
원본의 코드·문구·이미지는 쓰지 않았다. 전부 새로 작성했고, 콘텐츠는 SNOOZE · LIMEN 자료다.

## 실행

`RIMEN_WEB` 폴더에서 `python -m http.server 5178` → http://127.0.0.1:5178/ver2/
(미디어를 루트 `media/` 에서 같이 쓰므로 반드시 RIMEN_WEB 루트에서 서버를 띄운다)

## 페이지 · 인터랙션

| 주소 | 화면 | 인터랙션 |
|---|---|---|
| (첫 방문) | 인트로 | 가로줄·도트 패턴 위 선언문 SLEEP. / FOLLOW, / NOTICE, / WAKE. |
| `#/` | 메인 — 나와 타인의 기준 | ★ 커서(자각)가 닿으면 선이 점으로 부서졌다 이어짐 · 노드가 커서로 끌림 · 개념어 클릭 → 상세 · 가운데 "깨어날까요?" 클릭/스크롤 → About |
| `#/about` | 3D 별자리 (8개 개념) | 드래그 회전(관성) · 휠 · 별 클릭 → 그 안으로 날아감 |
| `#/about/:id` | 스포트라이트 | 전등 진자를 잡아 흔들기 · 빛이 닿는 곳만 읽힘 · 탭 전환 시 깜빡임 |
| `#/work` | 도면 격자 작업 목록 | 휠 한 칸씩 · 입자가 모여 이미지로 응결 · ALL / TEST / R&D 필터 · ↑↓ Enter |
| `#/work/:id` | 작업 상세 | 설명문 핵심어가 순서대로 선으로 이어짐 · 핵심어 호버 → 본문에 밑줄 · 들판 시차 |
| `#/visit` | 전시장 (벽 3 + 바닥 1) | 선·면·점 모드 · 호버하면 입자로 흩어지며 전시 정보 · 바닥에 관객의 흔적 |
| 공통 | | CRT 붕괴 전환 · 점+십자 커서 · 필름 그레인 · SOUND 토글(WebAudio 로 합성, 파일 없음) |
