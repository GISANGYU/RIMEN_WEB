## 2. 핵심 인터랙션의 원리 (재구현 명세)

**선이 점으로 부서지는 그래프 (메인)**
- 각 선을 N개의 샘플 점으로 본다. 점마다 커서까지 거리 d. `d < R` 이면 그 점을 선에서 떼어 입자로 만든다: 수직 방향으로 밀려나고(반발), 스프링으로 제자리에 돌아온다.
- 떨어진 구간은 선 대신 점으로 그린다 → "끊어진 점선". 커서가 떠나면 스프링이 되돌려 다시 선이 된다.
- 가운데 노드는 커서 방향으로 `lerp(중심, 커서, 0.06)` 만큼 끌려가고, 모든 선의 한쪽 끝이 노드라 그래프 전체가 기운다.

**CRT 붕괴 전환**
- 나가는 화면: `scaleY 1 → 0.003` (빠르게, ease-in) 동안 밝기 ↑ → 가로 흰 줄 → `scaleX → 0` → 점 → 암전.
- 들어오는 화면: 역순. 0.9초 안팎.

**스포트라이트 진자 (About 상세)**
- 전등 = 진자. `θ'' = -(g/L)·sinθ - c·θ'`. 드래그하면 θ 를 직접 잡아 당기고, 놓으면 흔들리다 멈춘다.
- 빛 = 전등 끝에서 아래로 퍼지는 원뿔. 본문 레이어에 원뿔 모양 `clip-path` → 빛 밖의 글은 안 보인다.

**입자 응결 썸네일 (Portfolio)**
- 이미지를 작게 샘플링해 밝은 픽셀 위치를 목표점으로. 입자는 흩어진 위치에서 목표로 수렴(감쇠 스프링) → 다 모이면 실제 이미지가 페이드인.

## 3. LIMEN 으로 번역 — 무엇을 무엇으로

LIMEN = "타인의 기준이 내 선택에 들어와 있음을 **알아차리는 순간**".
원본의 "점·선·면" 자리에 LIMEN 의 **"연결 · 흔적 · 자각"** 을 놓는다.

| 원본 | ver2 (LIMEN) | 의미 |
|---|---|---|
| 인트로 선언문 "점, 선, 면" | **SLEEP. / FOLLOW, / NOTICE, / WAKE.** | 잠든 채 따르다 → 알아차리고 → 깬다 |

| 가운데 노드 호버 "궁금해?" | **"깨어날까요?"** 사각형 | 클릭 = 문턱을 넘음 |

| 스포트라이트 전등 | 그대로 — **빛(자각)이 닿는 곳만 읽힌다** | LIMEN 의 핵심 은유와 정확히 일치 |
| Portfolio 도면 격자 | **WORK** — 우리 테스트 로그·R&D 작업 목록, 입자 응결 썸네일 | 흩어진 기록이 하나의 형태로 |
| Project 키워드 경로 | 작업 메모의 핵심어를 경로로 | 생각의 흐름 |
| Contact 다이아몬드 | **VISIT** — 다이아몬드 대신 **벽 3면 + 바닥 1면의 방(호라이즌 스튜디오)** 와이어프레임. 모드 `선·면·점` → `선(벽)·면(투사)·점(관객)` | 전시장 자체가 오브젝트 |
