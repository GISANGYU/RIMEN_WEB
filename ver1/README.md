# SNOOZE — Flow study

Lusion의 밝은 배경, 큰 타이포그래피, 넓은 미디어 레이아웃과 유연한 움직임을 참고한 별도 시안입니다. 기존 웹사이트와 팀 공동 작업 공간은 수정하지 않았습니다.

## 실행

이 폴더에서 `python -m http.server 8786 --bind 127.0.0.1`을 실행하고 http://127.0.0.1:8786 을 엽니다. `index.html`을 더블클릭하면 브라우저 보안 정책에 따라 WebGL 이미지가 제한될 수 있으므로 HTTP 미리보기를 사용합니다.

## 구성

- `index.html`: 콘텐츠, 이미지와 영상 연결
- `style.css`: 밝은 라벤더 톤, 타이포그래피, 모바일 레이아웃
- `app.js`: 대표 영상의 스크롤 위치 기반 곡면 확장, 히어로 포인터 물결, 갤러리 분류, 확대 보기, 영상 재생
- `assets/`: SNOOZE에서 확보한 실제 미디어와 로컬 폰트
- `vendor/`: 기존 프로젝트의 Three.js, Lenis

대표 영상에만 64×48 분할 평면을 사용합니다. 작은 썸네일(데스크톱 화면 폭 42%, 16:9)에서 폭 90%·높이 약 80%의 화면으로 확장합니다. 오른쪽 위부터 시작해 왼쪽 아래로 진행률에 차이를 주어 비대칭 곡면을 만들고, 확장 후 잠시 화면에 고정했다가 다음 섹션으로 이어집니다. 변형은 스크롤 위치만으로 결정되므로 스크롤 정지 시 멈추고 역스크롤 시 되돌아갑니다. 속도 기반 출렁임과 자동 상하 진동은 제거했으며 일반 갤러리는 정적인 사각형입니다. 히어로에는 마우스 물결만 유지했습니다. Lusion의 `home-reel-thumb`을 시각적으로 참고한 자체 구현으로, 원본 엔진과 동일한 코드는 아닙니다.

상단 ≈ 버튼으로 모션을 끌 수 있습니다. 시스템의 모션 감소 설정도 따릅니다. WebGL이 불가능하거나 컨텍스트가 손실되면 일반 이미지로 표시합니다. 터치 기기에서는 커서를 숨기며, 모바일 갤러리는 한 열입니다.
